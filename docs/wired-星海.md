# /wired/ 星海：一块实时字符画

## 入口怎么走

```text
za4ever.com/            入口门（EntryGate）
  ├─ ▶ ENTER          →  /wired/   星海分站
  └─ 静音进入主站      →  留在 /    主站首页
```

- 门只在「本次会话还没进过站」时出现（`sessionStorage.gate-passed`），而且必须由 JS 打标记才会显示：
  禁用 JS 的读者不会被锁在门外。
- ENTER 是一个真正的链接（`<a href="/wired/">`），中键 / 新标签页 / 无 JS 都能用；
  JS 只负责补一声进入音（Web Audio 合成，无音频文件）并记下会话标记。
- `/wired/` 自己不再设第二道门 —— 门只有一道，就在 `/` 上。

## 背景是怎么画出来的

全部实现在 `src/pages/wired/index.astro` 一个文件里（结构 + 样式 + 脚本，零外部依赖）。

1. **切网格**：量出等宽字符的真实字宽，把视口切成「列 × 行」的字符网格。
   桌面约 120 列，手机约 46 列。帧率跟不上会按 0.82 的倍率自动降列数（最低 0.5 倍）。
2. **算亮度**：每帧给每个格子算一组「亮度 + 色相 + 饱和度」，分五层叠加：

   | 层 | 内容 | 纵深手段 |
   | --- | --- | --- |
   | 星云 | 三层 fbm 噪声，阈值拉高，只让最密的区域结云 | 缓慢漂移；天空大部分留黑 |
   | 星 | 初始化时撒一次，亮度按深度分层 | 越近越亮，亮星带十字星芒 |
   | 月亮 | 一个圆盘 + 一圈很淡的光晕 | 全画面唯一的高光，也是海面光路的源头 |
   | 地平线 | 一条被噪声切碎的光带 | 天与海的分界，视距的最远处 |
   | 海面 | 浪线沿「距离」排布，近处一波占十几行、远处一行好几波 | 透视压缩 + 越近越暗 + 月光在水面碎成一条路 |

3. **选字形**：亮度 → 字符（ASCII 密度阶梯，或 01 的有序抖动）+ 颜色深浅。
   颜色查表提前算好（32 色相 × 4 饱和度 × 22 明度），渲染循环里只做整数索引，不产生字符串垃圾。

## 两个字集

- `ASCII`：` .,:;-~=+*#%@`，从暗到亮。暗到看不见的格子直接留空 —— 太空本来就该是黑的。
- `01`：只用 0 和 1。中间调用 4×4 有序抖动（Bayer）决定这一格写 0 还是 1，1 越密就越亮；
  空无一物的地方也铺一层很暗的 0，海面以下压得更暗，所以 01 模式下同样读得出纵深。

切换方式：首屏的字集开关、本地记忆（`localStorage`），或者直接用网址 `?charset=01`。

## 刻意删掉的「噪音」

上一版 `/wired/` 是 CRT 终端的样子，这一版全删了：
glitch 标题、扫描线、CRT 闪烁、跑马灯（ticker）、随机跳动的信号灯、可拖拽的 readme 弹窗、
悬停音效与 60Hz 底噪、88×31 站徽墙。

留下的动只有三种，而且都很慢：星在呼吸、浪在走、月亮在水里碎。
它们全部由确定性哈希与正弦驱动，**没有一帧随机数** —— 逐帧随机在字符画里就等于噪点。

## 性能与无障碍

- 渲染锁 30fps（`1000/30`），切到后台立刻停掉 `requestAnimationFrame`。
- 帧成本的移动平均超过 20ms 就降一档字符密度：宁可字符大一点，也不让风扇起飞。
- `prefers-reduced-motion: reduce` 下只画一帧静态画面，不做任何循环动画。
- 无 JS 时背景退化成同色系的 CSS 渐变，正文照常可读。
- 画布 `aria-hidden`，正文全部是真实 HTML，切换按钮带 `aria-pressed`。
- 没有闪烁（频率一律 ≤ 3Hz 的底线由此天然满足）。
