# /wired/ 星海：一块实时字符画

## 入口怎么走

```text
za4ever.com/            入口门（EntryGate）
  ├─ ▶ ENTER          →  /wired/   星海分站
  └─ 静音进入主站      →  留在 /    主站首页
```

- 门只在「本次会话还没进过站」时出现（`sessionStorage.gate-passed`），而且必须由 JS 打标记才会显示：
  禁用 JS 的读者不会被锁在门外。
- ENTER 是一个真正的链接（`<a href="/wired/">`），中键 / 新标签页 / 无 JS 都能用。
  普通左键也**完全交给浏览器自己跳**：不 `preventDefault`、不插延时 —— 按下去就是立刻换页
  （实测约 30–50ms 落地），门一直盖着直到新文档接手，中间不会闪出主站首页。
  曾经为了等一声进入音 `setTimeout(340)`，代价就是这半秒多的「停在主站」，已经删掉。
- 进入音搬到了 `/wired/` 上播。声音没法跨文档 —— 在门口响、页面立刻被换掉只会剩半声，
  所以门那边只在按下的瞬间写一个一次性标记（`sessionStorage['wired-enter-sound']`），
  落地页读它出声。这次跳转本身就是用户手势，浏览器会放行（实测 `AudioContext` 落页即
  `running`）；万一被自动播放策略拦下（换标签页打开、直接贴网址等），也只是没这一声。
- `/wired/` 自己不再设第二道门 —— 门只有一道，就在 `/` 上。

## 背景是怎么画出来的

全部实现在 `src/pages/wired/index.astro` 一个文件里（结构 + 样式 + 脚本，零外部依赖）。

1. **切网格**：量出等宽字符的真实字宽，把视口切成「列 × 行」的字符网格。
   一列约 7.2px：桌面约 200 列、手机约 55 列（上一版是 120 / 46，密了将近三倍）。
   帧率跟不上会按 0.82 的倍率自动降列数（最低 0.5 倍）。
2. **分三段**：`SKY_EDGE = 0.45`、`SEA_EDGE = 0.63` 把画面切成
   天空 → **流星带** → 海面。中间那段是后来新加的：天和海不再硬碰硬地接在一起。
3. **算亮度**：每帧给每个格子算一组「亮度 + 色相 + 饱和度」，分七层叠加：

   | 层 | 内容 | 纵深手段 |
   | --- | --- | --- |
   | 星云 | 三层 fbm 噪声，阈值拉高，只让最密的区域结云 | 跟着天空漂，速度最慢；天空大部分留黑 |
   | 流星带的雾 | 一层越往下越浓的噪声，紫转青 | 接住上面的星云，也接住下面的地平线 |
   | 流星 | 字符从带顶落向地平线，尾巴 4–10 行 | 亮度按落点走 sin 曲线：进场暗 → 中段最亮 → 熄灭 |
   | 星 | 初始化时撒一次，亮度按深度分层 | 越近越亮、走得越快；亮星带十字星芒 |
   | 月亮 | 一个圆盘 + 一圈很淡的光晕 | 全画面唯一的高光，也是海面光路的源头 |
   | 地平线 | 一条被噪声切碎的光带 | 流星带与海的分界，视距的最远处 |
   | 海面 | 浪线沿「距离」排布，近处一波占十几行、远处一行好几波 | 透视压缩 + 越近越暗 + 月光在水面碎成一条路 |

4. **让天空走起来**：`drift = t * SKY_DRIFT * cols`（0.0075 = 一分钟走掉小半个屏）。
   星云取 `drift * 0.36`、星取 `drift * (0.5 + 1.05z)`、月亮取 `drift * 0.78` ——
   同一个位移配三个系数，就是三层视差。所有会绕回另一端的东西（星、月）在两侧各留一段
   `smoothstep` 淡入淡出，换位那一瞬刚好淡到看不见，所以没有「啪」地跳一下。
   海面上那条月光路钉在月亮的横坐标上（`moonXs`），月亮往左挪一格，碎光就跟一格；
   月亮淡出时这条路也一起淡掉 —— 月亮落下去，海面是真的会暗下来的。

3. **选字形**：亮度 → 字符（ASCII 密度阶梯，或 01 的有序抖动）+ 颜色深浅。
   颜色查表提前算好（32 色相 × 4 饱和度 × 22 明度），渲染循环里只做整数索引，不产生字符串垃圾。

## 两个字集

- `ASCII`：` .,:;-~=+*#%@`，从暗到亮。暗到看不见的格子直接留空 —— 太空本来就该是黑的。
- `01`：只用 0 和 1。中间调用 4×4 有序抖动（Bayer）决定这一格写 0 还是 1，1 越密就越亮；
  空无一物的地方也铺一层很暗的 0，海面以下压得更暗，所以 01 模式下同样读得出纵深。

切换方式：首屏的字集开关、本地记忆（`localStorage`），或者直接用网址 `?charset=01`。

## 刻意删掉的「噪音」

上一版 `/wired/` 是 CRT 终端的样子，这一版全删了：
glitch 标题、扫描线、CRT 闪烁、跑马灯（ticker）、随机跳动的信号灯、可拖拽的 readme 弹窗、
悬停音效与 60Hz 底噪、88×31 站徽墙。

留下的动只有几种，而且都很慢：整片天空在往左漂、星在呼吸、浪在走、月亮在水里碎、流星一颗颗掉。
它们全部由确定性哈希、正弦与时间驱动，**没有一帧随机数** —— 逐帧随机在字符画里就等于噪点。

## 性能与无障碍

- 渲染锁 30fps（`1000/30`），切到后台立刻停掉 `requestAnimationFrame`。
- 帧成本的移动平均超过 20ms 就降一档字符密度：宁可字符大一点，也不让风扇起飞。
- `prefers-reduced-motion: reduce` 下只画一帧静态画面，不做任何循环动画。
- 无 JS 时背景退化成同色系的 CSS 渐变，正文照常可读。
- 画布 `aria-hidden`，正文全部是真实 HTML，切换按钮带 `aria-pressed`。
- 没有闪烁（频率一律 ≤ 3Hz 的底线由此天然满足）。

| 三段分界（天 / 流星带 / 海） | 脚本顶部的 `SKY_EDGE`、`SEA_EDGE` |
| 天空往左漂的速度 | 脚本顶部的 `SKY_DRIFT`（改大就更明显） |

| 星的数量与疏密 | `buildStars()` |
| 月亮的位置与大小 | `build()` 里的 `moonX0 / moonY / moonR` |
| 浪的疏密与速度 | 海面那段里的 `wavePhi += ...` |
| 整体配色 | `palette` 的生成循环 + CSS 里 `body` 的兜底渐变 |
| 字符阶梯 | `RAMPS` |

> 实测帧成本（无头 Chrome，device pixel ratio = 1）：1440×900 约 4.3ms / 帧，
> 2560×1440 约 4.2ms / 帧，390×844 约 2.1ms / 帧。预算（30fps）是 33ms，余量很大，
> 所以密度才敢往上加。
