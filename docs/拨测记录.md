# 拨测记录

用于留基线：**没有基线的"变慢了"是无法判断的**。每次测完填一行，出现劣化时才能分清是运营商波动、Cloudflare 入境质量变化，还是自己改坏了。

## 怎么测

1. 打开 [itdog.cn](https://www.itdog.cn/) → 网站测速（HTTP）
2. 输入正式域名（`https://example.com`）
3. 测点选 **移动 / 联通 / 电信 × 华东 / 华南 / 华北 / 西南**，至少 12 个
4. 记录下表的六个数（itdog 结果页会给出平均/最快/最慢与失败清单）

## 判据

| 指标 | 可接受 | 需要升级到路线 B |
| --- | --- | --- |
| 成功率 | ≥ 90% | < 90% |
| TTFB（平均） | < 1.5s | > 2.5s 或大量超时 |
| 首屏完全加载（平均） | < 5s | > 8s |

## 触发升级到路线 B 的条件

满足任一条再考虑加香港出口（见 [`技术路线.md`](技术路线.md) 第 4.2、5 节）：

- 连续两周成功率 < 90%
- 晚高峰 TTFB 中位数 > 2.5s
- 出现明确的"整个省份/整个运营商打不开"，且换网络可复现
